# SAYODA Digital Identity

موقع بطاقة شخصية رقمية من صفحة واحدة.

## الصور
ضع الصور بجانب `index.html` بهذه الأسماء:
- sayed.png
- sayed2.png
- sayed3.png
- ...
- sayed12.png

كل صورة لها مكان مستقل في قسم المعرض. إذا لم تضع صورة، سيظهر مكانها كـ ADD IMAGE.

## التشغيل
افتح `index.html` مباشرة أو ارفع الملفات كما هي على GitHub Pages / أي استضافة Static.

لا توجد قاعدة بيانات أو Backend.
